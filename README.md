# E-commerce Order Data Cleaning

## 📌 Project Overview

This project focuses on cleaning and preparing an e-commerce order dataset for further analysis.

The dataset was reviewed and cleaned in Microsoft Excel to improve its accuracy, consistency, and usability.

## 🧹 Data Cleaning Tasks

The following data-cleaning tasks were performed:

* Identified and handled missing cells
* Identified and removed duplicate records
* Standardized the date format
* Reviewed the dataset for consistency and accuracy

## 🛠️ Tools Used

* Microsoft Excel

## 📂 Dataset

The dataset contains e-commerce order information, including details about orders, customers, products, payment methods, order status, and other order-related information.

The workbook contains:

* **RAW** – Original dataset before cleaning
* **Updated** – Cleaned and updated version of the dataset

## 🎯 Project Objective

The objective of this project was to transform the raw e-commerce data into a cleaner and more consistent dataset that can be used for further analysis and reporting.
